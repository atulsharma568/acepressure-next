Copy acepressure, docs, tests and VERSION into the existing installation and replace program files. Preserve .env, .venv, data and data-demo. Restart Start.bat. Migration 005 adds an alias table automatically. No credentials or payment settings change.

## Correct Dinesh's duplicate

The merge is audited, including moved tip IDs; there is no one-click undo, so verify carefully and retain your backup.
